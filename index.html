Firewall Builder WebUI — package repo

Static apt + rpm repository hosted on GitHub Pages.

RPM (openSUSE / Fedora)

curl -fsSL https://net-aigis.github.io/fwbuilder/rpm/fwbuilder-webui.repo | sudo tee /etc/zypp/repos.d/fwbuilder-webui.repo
# Fedora/RHEL: use /etc/yum.repos.d/ instead
sudo zypper refresh && sudo zypper install fwbuilder-webui
# or: sudo dnf install fwbuilder-webui

APT (Debian / Ubuntu)

curl -fsSL https://net-aigis.github.io/fwbuilder/apt/fwbuilder-webui.list | sudo tee /etc/apt/sources.list.d/fwbuilder-webui.list
sudo apt update && sudo apt install fwbuilder-webui

Also see README.md and GitHub Releases (tarballs live on Releases — not on Pages).
