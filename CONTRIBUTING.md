# Contributing to Firewall Builder

Thank you for your interest in contributing to Firewall Builder!

Firewall Builder is an open-source firewall management project maintained and modernized by NetAigis.

## Reporting bugs

Please check existing issues before submitting a new report.

Use the Bug Report template and include:

- Firewall Builder version or Git commit
- Operating system and affected firewall backend
- Steps to reproduce the problem
- Expected and actual behavior
- Relevant logs or generated firewall configuration

Remove passwords, tokens and other sensitive information.

## Security vulnerabilities

Please use GitHub's **Private Vulnerability Reporting** feature.

Do not disclose security vulnerabilities through public issues.

## Contributing code

1. Fork the repository or create a development branch.
2. Keep changes focused and preserve compatibility with existing firewall backends.
3. Test the affected functionality.
4. Submit a pull request targeting `main`.
5. Explain the changes and provide relevant test results.

Existing GitHub Actions workflows are used for build and regression verification. 
Refer to the repository's current CI configuration for supported platforms and tests.

## Feature requests

Feature requests and improvement proposals are welcome through GitHub Issues.

Please describe the intended functionality, use cases and affected components.

## Licensing

Contributions must be compatible with the project's existing GPL licensing.

Thank you for helping maintain and improve Firewall Builder!
